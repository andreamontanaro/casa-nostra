# Dev Log — 6 giugno 2026

## Panoramica

Risolto un errore di compilazione riscontrato all'avvio in modalità di sviluppo (`npm run dev`) legato all'importazione del pacchetto `tw-animate-css` nel file `app/globals.css`.

---

## Dettaglio Implementazione

- **`app/globals.css`**: Modificato il percorso di importazione di `tw-animate-css` da `@import "tw-animate-css";` a `@import "../node_modules/tw-animate-css/dist/tw-animate.css";`. 
  - **Motivazione**: Il pacchetto `tw-animate-css` espone l'entry point CSS principale nel suo `package.json` definendo solo la condizione `"style"` all'interno dell'oggetto `"exports"`. Il resolver CSS di Turbopack (Next.js 16) non supporta pienamente questo tipo di configurazione durante la risoluzione del modulo implicito in CSS, causando un errore di tipo `Can't resolve 'tw-animate-css'`. L'utilizzo del percorso relativo diretto aggira il mapping delle esportazioni e risolve l'errore.
